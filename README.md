# Library-Management-System


A simple Library Management System developed in Java using Object-Oriented Programming concepts.

## Features

- Add Books
- Display Books
- Search Book by Title
- Issue Book
- Return Book

## Project Structure

LibraryManagementSystem/
│
├── Book.java
├── Library.java
├── Main.java
└── README.md

## Classes

### Book.java
Stores book information:
- Book ID
- Title
- Author
- Availability Status

### Library.java
Manages library operations:
- addBook()
- displayBooks()
- searchBook()
- issueBook()
- returnBook()

### Main.java
Driver class used to test all library functions.
